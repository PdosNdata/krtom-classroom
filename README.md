# คลังการเรียนรู้วิทยาการคำนวณ (ป.1–ม.3)

เว็บไซต์นี้เป็น **"โครงเว็บ" (skeleton)** ที่มีเมนู/หน้าครบทุกระดับชั้น ทุกวิชา ทุกหน่วยการเรียนรู้แล้ว
ส่วน **เนื้อหาจริง** (ใบความรู้ / ใบงาน / เกม / AR ของแต่ละหน่วย) ยังเป็น "กำลังจัดทำ" รอเติมทีหลังตามที่ตกลงกัน

## โครงสร้างไฟล์

```
เว็บไซต์การเรียนรู้/
├── index.html              ← หน้าเว็บหลัก (ตัวเว็บทั้งหมดเป็น SPA หน้าเดียว)
├── assets/
│   ├── css/style.css       ← ธีมสี/ดีไซน์ทั้งเว็บ
│   └── js/
│       ├── data.js         ← ★ ข้อมูลหลักสูตรทั้งหมด (แก้ชื่อหน่วย/เพิ่มหน่วยที่นี่)
│       └── app.js          ← ตัวจัดการหน้า/เมนู (routing) ไม่ต้องแก้ถ้าแค่เพิ่มเนื้อหา
├── ar-demo/
│   ├── webar.html          ← ตัวอย่าง WebAR ผ่านกล้องจริง (AR.js + มาร์กเกอร์ Hiro)
│   └── game-style.html     ← ตัวอย่างเกมสไตล์ AR แบบไม่ใช้กล้อง (ลากวางสติกเกอร์)
└── content/                ← (ว่างไว้) สำหรับเก็บไฟล์เนื้อหาที่จะเพิ่มทีหลัง
```

ไม่มี build step ใดๆ — เป็น HTML/CSS/JS ธรรมดา เปิดจาก `index.html` ได้เลย หรืออัปโหลดทั้งโฟลเดอร์ขึ้น hosting ของโรงเรียนตรงๆ

## วิธีนำขึ้นโดเมน/hosting ของโรงเรียน

1. อัปโหลดทั้งโฟลเดอร์ `เว็บไซต์การเรียนรู้/` ขึ้นไปที่ root ของเว็บ (เช่นผ่าน FTP/cPanel File Manager)
2. ตั้งให้ `index.html` เป็นหน้าแรกของโดเมน (ปกติ hosting ส่วนใหญ่ตั้งเป็นค่าเริ่มต้นอยู่แล้ว)
3. เนื่องจากใช้ hash-routing (`#/...`) จึงไม่ต้องตั้งค่า rewrite rule ใดๆ บนเซิร์ฟเวอร์ — ใช้ได้กับ hosting แบบ static ทั่วไปทันที
4. แนะนำให้ทำเว็บเป็น **https** (โฮสต์ส่วนใหญ่มี SSL ฟรีให้) เพราะ **ฟีเจอร์กล้องสำหรับ AR ต้องใช้ https เท่านั้น** (ยกเว้นทดสอบที่ localhost)

## วิธีเพิ่ม/แก้ชื่อหน่วยการเรียนรู้

แก้ไฟล์ `assets/js/data.js` เพียงไฟล์เดียว เช่น เพิ่มหน่วยใหม่ในชั้น ป.1:

```js
units: [
  { name: "การใช้งานเทคโนโลยีเบื้องต้น" },
  { name: "หน่วยใหม่ที่เพิ่ม" }   // ← เพิ่มบรรทัดแบบนี้
]
```

เมนู/จำนวนหน่วย/ลิงก์ทั้งหมดจะอัปเดตตามอัตโนมัติ ไม่ต้องแก้ไฟล์อื่น
