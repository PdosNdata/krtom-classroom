🎯 จุดประสงค์การเรียนรู้

  • อธิบายลักษณะของแนวคิดเชิงนามธรรมและนำไปใช้แยกสาระสำคัญของปัญหาได้
  • อธิบายและเขียนอัลกอริทึมด้วยภาษาธรรมชาติ รหัสลำลอง และผังงานได้
  • อธิบายแนวคิดเชิงคำนวณและความสำคัญของการคิดเชิงนามธรรมกับการแก้ปัญหาได้
  • อธิบายความหมายของบูลีนและใช้แก้ปัญหาในชีวิตประจำวันได้
  • ออกแบบอัลกอริทึมเพื่อแก้ปัญหาในชีวิตประจำวันและถ่ายทอดได้อย่างถูกต้อง

1 แนวคิดเชิงคำนวณ

แนวคิดเชิงคำนวณ (Computational Thinking) คือการแก้ปัญหาอย่างเป็น ระบบ และมี ลำดับขั้นตอนที่ชัดเจน เป็นวิธีคิดที่ทั้งมนุษย์และคอมพิวเตอร์เข้าใจร่วมกันได้ จึงเป็นพื้นฐานสำคัญของการพัฒนาซอฟต์แวร์ ช่วยให้ได้ผลลัพธ์ที่มีประสิทธิภาพ

🧩

การแยกย่อยปัญหา

แบ่งปัญหาใหญ่เป็นปัญหาย่อยที่จัดการได้ง่าย

🔁

การหารูปแบบ

มองหาสิ่งที่เหมือนหรือซ้ำกันในปัญหา

🔍

การคิดเชิงนามธรรม

คัดเฉพาะสาระสำคัญ ตัดรายละเอียดที่ไม่จำเป็น

📝

การออกแบบอัลกอริทึม

เขียนขั้นตอนแก้ปัญหาให้เรียงลำดับชัดเจน

🍕 ตัวอย่าง หาพื้นที่สามเหลี่ยมของพิซซา: พิซซารูปสามเหลี่ยมสูง 10 ซม. ฐาน 5 ซม. ใช้สูตร ½ × ฐาน × สูง ได้พื้นที่ 25 ตารางเซนติเมตร ถ้าแบ่งเป็น 2 ชิ้นเท่า ๆ กัน จะได้ชิ้นละ 12.5 ตารางเซนติเมตร และเขียนเป็นขั้นตอนเรียงลำดับด้วยภาษาธรรมชาติได้

2 แนวคิดเชิงนามธรรม

แนวคิดเชิงนามธรรม (Abstraction) เป็นองค์ประกอบหนึ่งของ แนวคิดเชิงคำนวณ คือการประเมินความสำคัญของรายละเอียดปัญหา แล้ว แยกส่วนที่เป็นสาระสำคัญ ออกจากส่วนที่ไม่ใช่สาระสำคัญ และพิจารณา จุดที่เหมือนกัน ของปัญหา เพื่อหาแนวคิดรวบยอด

🔍

ประโยชน์

ช่วยให้เข้าใจปัญหาและมองเห็นปัญหาได้ชัดเจนขึ้น และเลือกวิธีแก้ปัญหาได้มีประสิทธิภาพ

📐

ตัวอย่างคณิตศาสตร์

รูปคลี่ของทรงกระบอก ประกอบด้วยวงกลม 2 รูป และสี่เหลี่ยมผืนผ้า 1 รูป

💧

ตัวอย่างวิทยาศาสตร์

วัฏจักรของน้ำ เลือกเฉพาะ ระเหย → ควบแน่น → ตกเป็นฝน → ซึมลงดิน

🗣️

ตัวอย่างการนำเสนอ

ถ่ายทอดเฉพาะสาระสำคัญ ทำให้ถูกต้อง ชัดเจน และตรงประเด็น

💡 ตัวอย่าง: เลือกรูป สี่เหลี่ยมคางหมู ออกจากรูปเรขาคณิตอื่น โดยดูคุณสมบัติ คือ มี 4 ด้าน มีด้านขนานกัน 1 คู่ และด้านขนานยาวไม่เท่ากัน
และตัวอย่างปูหญ้า สนาม 10 × 5 ม. หญ้าผืนละ 50 × 50 ซม. สาระสำคัญคือขนาดสนามกับขนาดหญ้า (ใช้หญ้า 200 ผืน)

3 ความสำคัญของการคิดเชิงนามธรรมกับการแก้ปัญหา

ปัญหาหนึ่งอาจมีความซับซ้อน ผู้แก้ปัญหาจึงต้องใช้การคิดเชิงนามธรรมเพื่อ คัดแยกสิ่งที่ไม่เกี่ยวข้องออก เหลือเฉพาะส่วนที่จำเป็น การคิดแบบนี้ช่วยให้

  • ขั้นตอนการแก้ปัญหาลดลง
  • ประหยัดเวลา
  • ลดต้นทุน
  • ได้วิธีแก้ปัญหาที่ได้ผลจริง

กระบวนการแก้ปัญหามี 3 ส่วนหลัก คือ นำเข้า (INPUT) → ประมวลผล (PROCESS) → ผลลัพธ์ (OUTPUT) การคิดเชิงนามธรรมใช้ได้ในส่วนใดส่วนหนึ่งหรือทุกส่วนก็ได้ และควรคาดการณ์ข้อผิดพลาดที่อาจเกิดขึ้นไว้ล่วงหน้าเพื่อตรวจสอบและแก้ไข (Debugging)

🧋

ตัวอย่าง ชานมไข่มุก

ประกอบด้วย น้ำตาล (จากอ้อย) ชา (จากต้นชา) ไข่มุก (จากแป้งมันสำปะหลัง) และน้ำแข็ง กินมาก ๆ เสี่ยงโรคอ้วน เบาหวาน ความดันโลหิตสูง และโรคหัวใจ

🍳

ตัวอย่าง ผัดกะเพราหมูสับ

แยกวัตถุดิบหลัก (เนื้อสัตว์ ใบกะเพรา พริก กระเทียม) แล้วเปลี่ยนเนื้อสัตว์เป็นเมนูอื่นได้ด้วยวิธีเดียวกัน

🦁

ตัวอย่าง แผนที่สวนสัตว์

ใช้สัญลักษณ์แทนสัตว์แต่ละชนิด แล้วดูเฉพาะตำแหน่งและเส้นทาง ตัดรายละเอียดอื่นออก ช่วยวางแผนเที่ยวได้ง่าย

4 การคิดเชิงนามธรรมในชีวิตประจำวัน

เราใช้การคิดเชิงนามธรรมอยู่แล้วทุกวัน คือ ปรับและตัดทอนรายละเอียด เพื่อให้เห็นแก่นของเรื่อง และเชื่อมจากสิ่งที่เป็นรูปธรรมไปสู่สิ่งที่เป็นนามธรรม

😀

สัญลักษณ์แทนความรู้สึก

หน้ายิ้มแทนความสุข หน้าบึ้งแทนความโกรธ ภาพเดียวแทนความรู้สึกที่อธิบายยาว ๆ ได้

🗺️

แผนที่เดินทาง

จำเฉพาะถนน จุดเลี้ยว และระยะทาง ไม่ต้องจำทุกบ้านที่ผ่าน

🏞️

ค้นหาของดีที่บ้านเรา

เลือกสถานที่เด่นของจังหวัดมาจัดเส้นทาง ใช้ Google Maps หาระยะทางเปรียบเทียบเส้นทางที่ง่ายและสะดวกที่สุด

⚠️ ข้อควรระวัง: ถ้าเก็บข้อมูลไม่ครบหรือไม่ตรงวัตถุประสงค์ จะทำให้ตัดสินใจผิด ทำงานล่าช้า และเสียเวลา จึงต้องเลือกข้อมูลที่ จำเป็นและเพียงพอ

5 บูลีน (Boolean)

บูลีน เป็นชนิดข้อมูลที่ใช้อธิบายเหตุผลเชิงตรรกะ คิดโดย จอร์จ บูล (George Boole) นักคณิตศาสตร์ชาวอังกฤษ ข้อมูลบูลีนมีเพียง 2 ค่า คือ จริง (true) หรือ เท็จ (false) และเป็นพื้นฐานสำคัญของวงจรตรรกะในระบบดิจิทัลและการเขียนโปรแกรม

✅

true

เงื่อนไขเป็นจริง เช่น 5 > 3

❌

false

เงื่อนไขเป็นเท็จ เช่น 2 > 7

การเปลี่ยนข้อมูลที่อธิบายเป็นคำพูดให้เป็นบูลีน ทำได้โดยตั้งเป็น คำถามที่ตอบได้ว่าจริงหรือเท็จ เช่น "ปลาคาร์ปสีแดงมีครบทุกตัวหรือไม่" แล้วนำไปใช้กับคำสั่งเลือกกระทำในโปรแกรม

If (เงื่อนไข = true)
  { ทำงานส่วนที่ 1 }
else if (เงื่อนไขที่สอง = true)
  { ทำงานส่วนที่ 2 }
else
  { ทำงานส่วนที่ 3 }
  • If ตรวจสอบเงื่อนไข ถ้าเป็นจริงจึงทำงานในปีกกาของมัน
  • else ทำงานเมื่อเงื่อนไขก่อนหน้าเป็นเท็จทั้งหมด
🐟 กิจกรรม หาปลาคาร์ปด้วยบูลีน: ลิตา คุณแม่ และน้ำหวานนำปลาคาร์ปหลายสีมาจัดนิทรรศการ มีปลาตายไปบางตัว ให้ใช้เงื่อนไข If / else if / else ตรวจทีละสีว่ามีครบหรือไม่ เพื่อหาว่าปลาที่ตายเป็นสีใด และนับจำนวนปลาแต่ละสี

6 อัลกอริทึมเบื้องต้น

อัลกอริทึม (Algorithm) คือ ระเบียบวิธีหรือขั้นตอนวิธี ที่ใช้แก้ปัญหา อธิบายเป็นขั้นตอนที่ชัดเจน ใช้แก้ปัญหาทั่วไปที่พบในชีวิตประจำวัน ไม่ใช่เฉพาะกรณีใดกรณีหนึ่ง และเขียนได้ 3 รูปแบบ

💬

ภาษาธรรมชาติ

บรรยายขั้นตอนด้วยภาษามนุษย์

💻

รหัสลำลอง (Pseudo Code)

ลำลองคำสั่งด้วยประโยคภาษาอังกฤษหรือไทย

🔀

ผังงาน (Flowchart)

ใช้ภาพสัญลักษณ์และลูกศร

เลือกอัลกอริทึมที่มีประสิทธิภาพ เช่น การต่อโมเดลตัวต่อ 2 วิธี ได้ผลเหมือนกัน

  • วิธีที่ 1 ลองผิดลองถูก ขั้นตอนน้อยกว่า
  • วิธีที่ 2 เปิดคู่มือแล้วต่อตามขั้นตอน ขั้นตอนมากกว่า แต่ต่อได้ถูกต้อง จึงมีประสิทธิภาพมากกว่า
💡 ที่มาของคำ: "อัลกอริทึม" เพี้ยนมาจากชื่อนักคณิตศาสตร์ชาวเปอร์เซีย อัล-ควาริซมี

7 ภาษาคอมพิวเตอร์และภาษาธรรมชาติ

ภาษาธรรมชาติ คือภาษาที่มนุษย์ใช้สื่อสารกันตามเชื้อชาติ เช่น ไทย อังกฤษ จีน แต่คอมพิวเตอร์ไม่เข้าใจความหมายและไวยากรณ์ของภาษาธรรมชาติ จึงต้องมี ภาษาคอมพิวเตอร์ ซึ่งเป็นภาษาประดิษฐ์ (Artificial Language) ที่โปรแกรมเมอร์เขียนขึ้นเพื่อสั่งงาน

ภาษาคอมพิวเตอร์แบ่งเป็น 5 ยุค ได้แก่ ภาษาเครื่อง → ภาษาแอสเซมบลี → ภาษาชั้นสูง → ภาษาขั้นสูงมาก → ภาษาธรรมชาติ

⚙️

ระดับต่ำ

เช่น ภาษาเครื่อง แอสเซมบลี ควบคุมฮาร์ดแวร์ได้ตรงและรวดเร็ว แต่มนุษย์เข้าใจยาก

🧱

ระดับกลาง

มีโครงสร้าง นำข้อดีของระดับต่ำและสูงมารวมกัน นิยมใช้แพร่หลาย

🌐

ระดับสูง

เข้าใจง่าย ใกล้ภาษาอังกฤษ แล้วถูกแปลงเป็นภาษาเครื่องให้คอมพิวเตอร์ทำงาน

💡 ควรรู้: บุคคลที่ได้รับการยกย่องเป็น โปรแกรมเมอร์คนแรกของโลก คือ เอดา ไบรอน (Ada Byron)

8 การเขียนอัลกอริทึมด้วยรหัสลำลอง

รหัสลำลอง (Pseudo Code) คือรูปแบบภาษาที่มีโครงสร้างชัดเจน กระชับ ใช้อธิบายขั้นตอนของอัลกอริทึม โดยไม่ขึ้นกับภาษาคอมพิวเตอร์ภาษาใด และแปลงเป็นภาษาคอมพิวเตอร์ได้ง่าย แต่ ไม่ใช่ภาษาโปรแกรม จึงสั่งให้คอมพิวเตอร์ทำงานจริงไม่ได้

หลักเกณฑ์การเขียน

  • ใช้คำสั่งสั้น กระชับ เข้าใจง่าย เช่น START = เริ่มต้น, STOP = สิ้นสุด
  • มีหมายเลขลำดับขั้นตอนชัดเจน และไม่จำเป็นต้องมีเครื่องหมายวรรคตอน
  • ไม่ขึ้นกับภาษาคอมพิวเตอร์ภาษาใดภาษาหนึ่ง
  • 1 บรรทัด มี 1 คำสั่ง เขียนจากบนลงล่าง มีจุดสิ้นสุดจุดเดียว
🏁

เริ่มต้น/สิ้นสุด

START, STOP, BEGIN, END

📥

รับข้อมูล

READ, GET, INPUT

📤

แสดงผล

WRITE, DISPLAY, SHOW, PRINT, OUTPUT

ประโยชน์: วางโครงร่างกระบวนการ เป็นต้นแบบทบทวนและแก้ไขโปรแกรม และกำหนดงานให้โปรแกรมเมอร์นำไปพัฒนา

9 การเขียนอัลกอริทึมด้วยผังงาน

ผังงาน (Flowchart) คือการใช้ ภาพสัญลักษณ์ แสดงลำดับขั้นตอนการทำงานของอัลกอริทึม ตั้งแต่เริ่มต้นจนได้ผลลัพธ์ เขียนจากบนลงล่าง หรือซ้ายไปขวา และต้องมี หัวลูกศร บอกทิศทาง

รูปแบบผังงาน 3 แบบ

  1. แบบเรียงลำดับ (Sequence) ทำงานเรียงจากบนลงล่าง ง่ายที่สุด ไม่มีทางเลือกหรือการทำซ้ำ
  2. แบบเลือกกระทำ/เงื่อนไข (Selection) เปรียบเทียบข้อมูล ถ้าจริงทำอย่างหนึ่ง ถ้าเท็จทำอีกอย่าง
  3. แบบทำซ้ำ (Loop) ทำกระบวนการซ้ำหลายครั้ง ขึ้นกับเงื่อนไขที่กำหนด
💡 หลักการเขียนที่ดี: ใช้สัญลักษณ์มาตรฐาน มีจุดเริ่มต้นและสิ้นสุดอย่างละจุด เขียนคำอธิบายสั้น ๆ ในสัญลักษณ์ ช่วยให้แยกแยะปัญหา เห็นลำดับ หาข้อผิดพลาด และอ่านเข้าใจง่าย ไม่ขึ้นกับภาษาใด

ตัวอย่างที่ 2 ตรวจผลการเรียน คะแนนเต็ม 100 ได้ตั้งแต่ 50 ขึ้นไป แสดง "สอบผ่าน" ไม่ถึง 50 แสดง "สอบไม่ผ่าน" (ใช้ผังงานแบบเลือกกระทำ)

START
INPUT score
IF score >= 50 THEN OUTPUT "สอบผ่าน"
ELSE OUTPUT "สอบไม่ผ่าน"
STOP

ตัวอย่างที่ 3 สูตรคูณแม่ 2 (ใช้ผังงานแบบทำซ้ำ) เริ่มที่ 1 คูณ 2 แสดงผล แล้วบวกเพิ่มทีละ 1 ทำซ้ำจนไม่เกิน 12

counter = 1
REPEAT: result = 2 * counter → OUTPUT result → counter = counter + 1
ทำซ้ำเมื่อ counter <= 12
💡 ควรรู้: เครื่องหมาย × ใช้ * และ ÷ ใช้ / ในการเขียนโปรแกรม

📌 สรุปท้ายหน่วย

  • แนวคิดเชิงคำนวณ คือการแก้ปัญหาอย่างเป็นระบบเป็นลำดับขั้นตอน มีองค์ประกอบ เช่น การแยกย่อยปัญหา การหารูปแบบ การคิดเชิงนามธรรม และการออกแบบอัลกอริทึม
  • แนวคิดเชิงนามธรรม คือการคัดแยกสาระสำคัญออกจากรายละเอียดปลีกย่อย ช่วยให้เข้าใจปัญหาชัดเจนขึ้น
  • บูลีนเป็นชนิดข้อมูลที่มีค่า จริง (true) หรือ เท็จ (false) ใช้ตรวจเงื่อนไขในโปรแกรม
  • อัลกอริทึม คือขั้นตอนวิธีแก้ปัญหาอย่างเป็นระบบ ควรเลือกวิธีที่มีประสิทธิภาพที่สุด
  • เขียนได้ 3 รูปแบบ คือ ภาษาธรรมชาติ รหัสลำลอง (Pseudo Code) และผังงาน (Flowchart)
  • ผังงานมี 3 แบบ คือ เรียงลำดับ เลือกกระทำ/เงื่อนไข และทำซ้ำ
  • คอมพิวเตอร์ไม่เข้าใจภาษาธรรมชาติ จึงต้องใช้ภาษาคอมพิวเตอร์ ซึ่งมี 5 ยุค
