ลากรายการไปวางให้ถูกต้องทั้ง 3 ตอน ลากเปลี่ยนที่ได้จนกว่าจะพอใจ แล้วกดส่ง ครูจะตรวจและแจ้งผลให้ · ใช้นิ้วแตะเลือกชิ้นแล้วแตะช่องปลายทางก็ได้

ตอนที่ 1 ประเภทของโปรแกรมค้นหา (ลากชื่อไปวางให้ตรงกับลักษณะ)

Crawler Based Search Engine
Web Directory
Meta Search Engine (Meta Tag)
ใช้ซอฟต์แวร์ขนาดเล็กไปเก็บข้อมูลจากเว็บไซต์ต่าง ๆ มาบันทึกในฐานข้อมูล แม่นยำและเร็ว นิยมมากที่สุด
รวบรวมเว็บไซต์เป็นสารบัญแยกหมวดหมู่ชัดเจน เหมาะกับการค้นข้อมูลเฉพาะด้าน
ค้นจากคำสั่งที่กำหนดรายละเอียดเว็บไซต์ เช่น ชื่อเว็บ ผู้แต่ง คำสำคัญ ความแม่นยำน้อยกว่าประเภทอื่น

ตอนที่ 2 เทคนิคการค้นหา (ลากไปวางให้ตรงกับผลที่ได้)

เครื่องหมายบวก ( + )
เครื่องหมายลบ ( - )
เครื่องหมายอัญประกาศ ( " " )
คำว่า OR
เพิ่มความสำคัญของคำนั้นในการค้นหา เช่น สถานที่ท่องเที่ยว+ทะเล
ตัดคำที่ไม่ต้องการออกจากผลลัพธ์ เช่น ผลไม้ -มะม่วง
ค้นหาเป็นกลุ่มคำที่ต้องเรียงติดกันตามที่พิมพ์
ค้นหาโดยให้พบคำใดคำหนึ่งในสองคำ

ตอนที่ 3 ขั้นตอนการสืบค้น (ลากไปวางให้ตรงกับการทำงาน)

กำหนดวัตถุประสงค์และหัวข้อ
กำหนดประเภทของข้อมูล
กำหนดคำสำคัญ
ประเมินความน่าเชื่อถือของข้อมูล
ตั้งเป้าหมายและหัวข้อให้ชัดเจน เพื่อกำหนดขอบเขตไม่ให้กว้างเกินไป
เลือกว่าต้องการข้อความ ภาพ หรือวิดีโอ เพื่อลดเวลาค้นหา
เลือกคำที่ตรงกับข้อมูลที่ต้องการ เพราะโปรแกรมค้นหาแสดงผลจากคำนี้
คัดเลือกเฉพาะข้อมูลที่ถูกต้องและมีคุณค่าจากผลที่ได้
