กดปุ่ม "▶ ทดลองรัน" เพื่อให้คอมพิวเตอร์ทำตามรหัสลำลองของคุณ

📖 คำสั่งที่ใช้ได้

      

        START / END เริ่มต้น / จบ

        INPUT a, b รับค่า

        SET x = 0 กำหนดค่า · COMPUTE x = a + b คำนวณ

        DISPLAY x หรือ "ข้อความ" แสดงผล

        DO ทำอะไรสักอย่าง (ข้อความ)

        IF เงื่อนไข THEN … ELSE … ENDIF

        WHILE เงื่อนไข DO … ENDWHILE

        เครื่องหมาย: + − * / mod  = <> > < >= <=  AND OR NOT

        ขึ้นต้น // = หมายเหตุ (ไม่ทำงาน)
