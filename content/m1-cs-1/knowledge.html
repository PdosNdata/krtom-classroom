การออกแบบและการเขียนโปรแกรมเบื้องต้น · ม.1 · วิทยาการคำนวณ

← กลับหน้าหน่วย

🎯 จุดประสงค์การเรียนรู้

  • อธิบายหลักการเขียนโปรแกรมและความแตกต่างของโปรแกรมภาษาต่าง ๆ ได้
  • อธิบายซอฟต์แวร์ที่ใช้เขียนโปรแกรม และแนวคิดเรื่องตัวแปร เงื่อนไข วนซ้ำได้
  • ออกแบบอัลกอริทึมและเขียนโปรแกรมอย่างง่ายเพื่อแก้ปัญหาทางคณิตศาสตร์ได้

1 หลักการเขียนโปรแกรมเบื้องต้น

โปรแกรมคอมพิวเตอร์ คือชุดคำสั่งที่เขียนขึ้นให้คอมพิวเตอร์ทำงานตามเงื่อนไข ผู้เขียนต้องเลือกภาษาให้เหมาะสมกับงาน และเข้าใจ โครงสร้างและไวยากรณ์ ของภาษานั้น หลักการเขียนโปรแกรมมี 4 ขั้นตอน

  1. กำหนดและวิเคราะห์ปัญหา (Analysis) — ทำความเข้าใจปัญหา และกำหนดวัตถุประสงค์
  2. ออกแบบโปรแกรม (Design) — ออกแบบอัลกอริทึมและหน้าจอการทำงาน
  3. เขียนโปรแกรม (Programming) — เขียนชุดคำสั่งด้วยภาษาโปรแกรม
  4. ทดสอบโปรแกรม (Testing) — ตรวจสอบความถูกต้อง แก้ไขข้อผิดพลาด

การวิเคราะห์ปัญหา (ข้อ 1–4) ประกอบด้วย 4 องค์ประกอบ

🎯

1. วัตถุประสงค์

โปรแกรมต้องการทำอะไร

📥

2. ข้อมูลนำเข้า (Input)

รับข้อมูลอะไร ชนิดใด กำหนดตัวแปร

⚙️

3. การประมวลผล (Process)

ใช้วิธีหรือสูตรคำนวณอะไร

📤

4. ข้อมูลนำออก (Output)

ผลลัพธ์คืออะไร กำหนดตัวแปร

จากนั้นออกแบบอัลกอริทึมและเขียนโปรแกรมต่อ (ข้อ 5–8) เมื่อวิเคราะห์ปัญหาแล้ว ให้ทำต่อจนครบ 8 ขั้น

📝

5. เขียนอัลกอริทึมแบบธรรมชาติ

บอกขั้นตอนเป็นข้อความภาษาไทย เรียงจากเริ่มต้นจนจบ

💻

6. เขียนอัลกอริทึมด้วยรหัสลำลอง

ใช้คำสั่งสั้น ๆ เช่น START, INPUT, COMPUTE, DISPLAY, END

🔷

7. เขียนผังงาน (Flowchart)

วาดสัญลักษณ์และลูกศรแสดงลำดับการทำงาน

🧱

8. เขียนโปรแกรม

นำอัลกอริทึมไปเขียนเป็นโปรแกรม เช่น ต่อบล็อกใน โค้ดจิ๊กซอว์

💡 ตัวอย่าง: โปรแกรมหาพื้นที่สี่เหลี่ยมผืนผ้า — Input: width, length (จำนวนเต็ม) / Process: Area = width × length / Output: Area

2 การออกแบบโปรแกรมและโครงสร้างการทำงาน

การออกแบบโปรแกรมแบ่งเป็น 2 ลักษณะ คือ

🔀

ออกแบบอัลกอริทึม

ลำดับขั้นตอนก่อนหลัง เขียนได้ด้วยภาษาธรรมชาติ รหัสลำลอง หรือผังงาน

🖥️

ออกแบบส่วนติดต่อผู้ใช้ (UI)

หน้าจอที่ใช้งานง่าย ไม่ซับซ้อน ข้อความสั้น กระชับ

โครงสร้างการทำงานของโปรแกรม มี 3 แบบ

➡️

เรียงลำดับ (Sequence)

ทำเรียงทีละขั้น ไม่ข้าม ไม่ย้อนกลับ

🔀

เงื่อนไข (Selection/Condition)

ตัดสินใจ เลือกทำตามเงื่อนไขที่ตรวจสอบแล้ว

🔁

ทำซ้ำ (Iteration/Loop)

ทำงานเดิมซ้ำ โดยมีเงื่อนไขกำหนดจำนวนรอบ

ตัวอย่างโครงสร้างการทำงาน อย่างละ 2 ตัวอย่าง — แต่ละตัวอย่างทำครบตามกระบวนการ: วัตถุประสงค์ → ข้อมูลนำเข้า → วิธีประมวลผล → ข้อมูลนำออก → อัลกอริทึม (ธรรมชาติ / รหัสลำลอง / ผังงาน) กดที่ชื่อตัวอย่างเพื่อเปิดดู

➡️ เรียงลำดับ (Sequence)

ตัวอย่างที่ 1: แปรงฟัน
โปรแกรมช่วยจำขั้นตอนการแปรงฟัน
1. วัตถุประสงค์ เพื่อแปรงฟันให้สะอาด
2. ข้อมูลนำเข้า
แปรงสีฟัน ยาสีฟัน และน้ำสะอาด
3. วิธีประมวลผล
บีบยาสีฟันลงบนแปรง แล้วแปรงฟันประมาณ 2 นาที
4. ข้อมูลนำออก ฟันสะอาด ปากสะอาด
5. เขียนอัลกอริทึมแบบธรรมชาติ
เริ่มต้น
หยิบแปรงสีฟัน
บีบยาสีฟันลงบนแปรง
แปรงฟันประมาณ 2 นาที
บ้วนปาก
จบ
6. เขียนอัลกอริทึมด้วยรหัสลำลอง
START
    DO หยิบแปรงสีฟัน
    DO บีบยาสีฟัน
    DO แปรงฟัน 2 นาที
    DO บ้วนปาก
END
7. เขียนผังงาน (Flowchart)
8. เขียนโปรแกรม โค้ดจิ๊กซอว์ ให้ระบบต่อบล็อกให้ แล้วกดธงเขียวเพื่อรันดูผล
🧱 เปิดโค้ดจิ๊กซอว์ — ระบบเขียนโปรแกรมให้
ตัวอย่างที่ 2: หาพื้นที่สี่เหลี่ยมผืนผ้า
โปรแกรมคำนวณหาพื้นที่สี่เหลี่ยมผืนผ้า
1. วัตถุประสงค์ เพื่อคำนวณหาพื้นที่สี่เหลี่ยมผืนผ้า
2. ข้อมูลนำเข้า
width คือ ความกว้าง เป็นตัวเลข
length คือ ความยาว เป็นตัวเลข
3. วิธีประมวลผล
สูตรพื้นที่ area = width × length
4. ข้อมูลนำออก แสดงพื้นที่สี่เหลี่ยมผืนผ้า
5. เขียนอัลกอริทึมแบบธรรมชาติ
เริ่มต้น
รับ ความกว้าง (width) เป็นตัวเลข
รับ ความยาว (length) เป็นตัวเลข
คำนวณ พื้นที่ area = width × length
แสดง ค่า area
จบ
6. เขียนอัลกอริทึมด้วยรหัสลำลอง
START
    INPUT width, length
    COMPUTE area = width * length
    DISPLAY area
END
7. เขียนผังงาน (Flowchart)
8. เขียนโปรแกรม โค้ดจิ๊กซอว์ ให้ระบบต่อบล็อกให้ แล้วกดธงเขียวเพื่อรันดูผล
🧱 เปิดโค้ดจิ๊กซอว์ — ระบบเขียนโปรแกรมให้

🔀 เงื่อนไข (Selection)

ตัวอย่างที่ 1: ตรวจผลสอบ
โปรแกรมตรวจผลสอบผ่านหรือไม่ผ่าน
1. วัตถุประสงค์ เพื่อตรวจสอบว่านักเรียนสอบผ่านหรือไม่
2. ข้อมูลนำเข้า
score คือ คะแนนสอบ เป็นตัวเลข
3. วิธีประมวลผล
ตรวจสอบเงื่อนไข ถ้า score เท่ากับหรือมากกว่า 50 ถือว่าผ่าน ถ้าไม่ใช่ถือว่าไม่ผ่าน
4. ข้อมูลนำออก แสดงคำว่า ผ่าน หรือ ไม่ผ่าน
5. เขียนอัลกอริทึมแบบธรรมชาติ
เริ่มต้น
รับ คะแนนสอบ (score) เป็นตัวเลข
ตรวจสอบ ถ้า score เท่ากับหรือมากกว่า 50 ให้แสดง "ผ่าน"
ไม่เช่นนั้น ให้แสดง "ไม่ผ่าน"
จบ
6. เขียนอัลกอริทึมด้วยรหัสลำลอง
START
    INPUT score
    IF score >= 50 THEN
        DISPLAY "ผ่าน"
    ELSE
        DISPLAY "ไม่ผ่าน"
    ENDIF
END
7. เขียนผังงาน (Flowchart)
8. เขียนโปรแกรม โค้ดจิ๊กซอว์ ให้ระบบต่อบล็อกให้ แล้วกดธงเขียวเพื่อรันดูผล
🧱 เปิดโค้ดจิ๊กซอว์ — ระบบเขียนโปรแกรมให้
ตัวอย่างที่ 2: เลขคู่หรือเลขคี่
โปรแกรมตรวจว่าเป็นเลขคู่หรือเลขคี่
1. วัตถุประสงค์ เพื่อตรวจสอบว่าจำนวนเต็มที่ใส่เป็นเลขคู่หรือเลขคี่
2. ข้อมูลนำเข้า
n คือ จำนวนเต็มที่ผู้ใช้ใส่
3. วิธีประมวลผล
นำ n หารเอาเศษด้วย 2 ถ้าเศษเป็น 0 เป็นเลขคู่ ถ้าเศษเป็น 1 เป็นเลขคี่
4. ข้อมูลนำออก แสดงคำว่า เลขคู่ หรือ เลขคี่
5. เขียนอัลกอริทึมแบบธรรมชาติ
เริ่มต้น
รับ จำนวนเต็ม n
คำนวณ เศษของ n หารด้วย 2
ตรวจสอบ ถ้าเศษเท่ากับ 0 ให้แสดง "เลขคู่"
ไม่เช่นนั้น ให้แสดง "เลขคี่"
จบ
6. เขียนอัลกอริทึมด้วยรหัสลำลอง
START
    INPUT n
    COMPUTE r = n mod 2
    IF r = 0 THEN
        DISPLAY "เลขคู่"
    ELSE
        DISPLAY "เลขคี่"
    ENDIF
END
7. เขียนผังงาน (Flowchart)
8. เขียนโปรแกรม โค้ดจิ๊กซอว์ ให้ระบบต่อบล็อกให้ แล้วกดธงเขียวเพื่อรันดูผล
🧱 เปิดโค้ดจิ๊กซอว์ — ระบบเขียนโปรแกรมให้

🔁 ทำซ้ำ (Loop)

ตัวอย่างที่ 1: วาดสี่เหลี่ยมจัตุรัส (ทำซ้ำตามจำนวนรอบ)
โปรแกรมวาดสี่เหลี่ยมจัตุรัส
1. วัตถุประสงค์ เพื่อวาดสี่เหลี่ยมจัตุรัสที่มีด้านยาวด้านละ 100 ก้าว
2. ข้อมูลนำเข้า
จำนวนด้าน 4 ด้าน และตัวนับรอบ i เริ่มที่ 1
3. วิธีประมวลผล
ทำซ้ำ 4 รอบ แต่ละรอบเดิน 100 ก้าว แล้วหมุนขวา 90 องศา
4. ข้อมูลนำออก ได้ภาพสี่เหลี่ยมจัตุรัสบนเวที
5. เขียนอัลกอริทึมแบบธรรมชาติ
เริ่มต้น
กำหนด i = 1
ทำซ้ำในขณะที่ i น้อยกว่าหรือเท่ากับ 4
เดิน 100 ก้าว แล้วหมุนขวา 90 องศา
เพิ่มค่า i อีก 1
จบ
6. เขียนอัลกอริทึมด้วยรหัสลำลอง
START
    SET i = 1
    WHILE i <= 4 DO
        DO เดิน 100 ก้าว
        DO หมุนขวา 90 องศา
        COMPUTE i = i + 1
    ENDWHILE
END
7. เขียนผังงาน (Flowchart)
8. เขียนโปรแกรม โค้ดจิ๊กซอว์ ให้ระบบต่อบล็อกให้ แล้วกดธงเขียวเพื่อรันดูผล
🧱 เปิดโค้ดจิ๊กซอว์ — ระบบเขียนโปรแกรมให้
ตัวอย่างที่ 2: หาผลรวม 1 ถึง 5 (ทำซ้ำตามเงื่อนไข)
โปรแกรมหาผลรวมของเลข 1 ถึง 5
1. วัตถุประสงค์ เพื่อหาผลรวมของจำนวนเต็ม 1 + 2 + 3 + 4 + 5
2. ข้อมูลนำเข้า
count คือ ตัวนับ เริ่มที่ 1
total คือ ผลรวม เริ่มที่ 0
3. วิธีประมวลผล
ทำซ้ำในขณะที่ count น้อยกว่าหรือเท่ากับ 5 โดยบวก count เข้าใน total แล้วเพิ่ม count อีก 1
4. ข้อมูลนำออก แสดงค่า total (ได้ 15)
5. เขียนอัลกอริทึมแบบธรรมชาติ
เริ่มต้น
กำหนด total = 0 และ count = 1
ทำซ้ำในขณะที่ count น้อยกว่าหรือเท่ากับ 5
คำนวณ total = total + count
เพิ่มค่า count อีก 1
แสดง ค่า total
จบ
6. เขียนอัลกอริทึมด้วยรหัสลำลอง
START
    SET total = 0
    SET count = 1
    WHILE count <= 5 DO
        COMPUTE total = total + count
        COMPUTE count = count + 1
    ENDWHILE
    DISPLAY total
END
7. เขียนผังงาน (Flowchart)
8. เขียนโปรแกรม โค้ดจิ๊กซอว์ ให้ระบบต่อบล็อกให้ แล้วกดธงเขียวเพื่อรันดูผล
🧱 เปิดโค้ดจิ๊กซอว์ — ระบบเขียนโปรแกรมให้
💡 ลองสร้างตัวอย่างเหล่านี้ด้วยปุ่ม 🧱 โค้ดจิ๊กซอว์ ในแท็บเกม — ตัวอย่างสี่เหลี่ยมจัตุรัสและตรวจคะแนนมีให้โหลดในเมนู "ตัวอย่างโปรแกรม"

การทำซ้ำมี 3 ประเภท: ทำซ้ำตามจำนวนรอบที่ระบุ, ทำซ้ำในขณะที่เงื่อนไขเป็นจริง, ทำซ้ำจนกระทั่งเงื่อนไขเป็นจริง

💡 ตัวแปร: ใช้เก็บข้อมูลในโปรแกรม ควรตั้งชื่อให้สอดคล้องกับข้อมูล เช่น width เก็บความกว้าง

3 การเขียนและทดสอบโปรแกรม

การเขียนโปรแกรมต้องเขียนชุดคำสั่งตามโครงสร้างและไวยากรณ์ของภาษา ชุดคำสั่งที่ได้เรียกว่า รหัสต้นฉบับ (Source Code) ขั้นตอนการเขียนโปรแกรม

  1. การให้รหัส (Coding) — เขียนชุดคำสั่งให้ถูกต้องตามไวยากรณ์
  2. แปลภาษา (Compile) — ตัวแปลภาษา (Compiler) แปลเป็นภาษาคอมพิวเตอร์
  3. ดำเนินงาน (Run) — เรียกใช้โปรแกรมให้ทำงาน

คำสั่งพื้นฐาน: ประกาศตัวแปร, รับค่า, คำนวณ/ประมวลผล, แสดงผล

การทดสอบโปรแกรม ทำก่อนนำไปใช้จริง เพื่อหาข้อผิดพลาด

⬛

Black Box Testing

ดูเฉพาะข้อมูลนำเข้าและผลลัพธ์ ไม่ดูการประมวลผลภายใน เหมือนกล่องดำ

⬜

White Box Testing

ตรวจทั้งผลลัพธ์และการประมวลผลภายในโปรแกรม เหมือนกล่องโปร่งใส ซับซ้อนกว่า

💡 ตัวอย่าง Black Box: ใส่ความกว้าง = 5 ความยาว = 10 โปรแกรมควรแสดงพื้นที่ = 50

4 ภาษาโปรแกรมที่ควรรู้จัก

ภาษาแต่ละภาษามีประวัติ โครงสร้าง และจุดเด่นต่างกัน

🇨

ภาษาซี (C)

พัฒนาโดย เดนนิส ริตชี่ (Bell Labs) ราวปี ค.ศ. 1969–1973 ใช้พัฒนาเกม ระบบปฏิบัติการ แอปมือถือ คำสั่งจบด้วย ; เช่น printf แสดงผล scanf รับค่า

🧩

สแครช (Scratch)

เขียนโปรแกรมแบบกราฟิก ลากบล็อก ประกอบด้วย เวที (Stage) ตัวละคร (Sprite) และสคริปต์ (Script) มีบล็อก 9 กลุ่ม เช่น Motion Looks Sound Events Control

🐍

ไพทอน (Python)

พัฒนาโดย กีโด ฟัน รอสซัม เป็นโอเพนซอร์ส ไวยากรณ์เรียบง่าย ใช้ print() แสดงผล input() รับค่า

☕

จาวา (Java)

พัฒนาโดย เจมส์ กอสลิง (Sun Microsystems) เป็นภาษาเชิงวัตถุ "เขียนครั้งเดียว รันได้ทุกที่" โครงสร้าง Import / Package / Class

💡 เครื่องหมายในไพทอน: + บวก, - ลบ, * คูณ, / หาร, % เศษของการหาร, ** ยกกำลัง, // หารปัดเศษทิ้ง

5 ตัวอย่างโปรแกรมและการตรวจหาข้อผิดพลาด

ตัวอย่าง คำนวณส่วนลดราคาสินค้า (ลด 10%)

  1. วิเคราะห์: วัตถุประสงค์ คำนวณส่วนลด Input = price (ราคาปกติ) Output = discount
  2. ประมวลผล: temp = price / 100 แล้ว discount = 10 × temp
  3. ออกแบบอัลกอริทึม แล้วเขียนเป็นโปรแกรม
START
INPUT price
COMPUTE temp = price / 100
COMPUTE discount = 10 * temp
OUTPUT discount
STOP

ตรวจสอบข้อผิดพลาดของโปรแกรม หลังเขียนเสร็จ ต้องตรวจว่าเขียนถูกไวยากรณ์และผลลัพธ์ถูกต้องหรือไม่ ถ้าผิดเพียงตัวเดียวโปรแกรมจะรัน (Run) ไม่ได้ ภาษาไพทอนจะแจ้งตำแหน่งข้อผิดพลาด ให้แก้ไขแล้วรันใหม่จนถูกต้อง

💡 การใช้ print(): แสดงข้อความต้องอยู่ในเครื่องหมายอัญประกาศ เช่น print("Hello World") แต่แสดงค่าในตัวแปรไม่ต้องใส่ เช่น print(x)

6 ทำความรู้จัก Scratch และบล็อกคำสั่งเบื้องต้น

Scratch เป็นภาษาโปรแกรมแบบบล็อก ผู้เขียนนำบล็อกคำสั่งมาวางต่อกันทีละคำสั่งตามขั้นตอนที่ต้องการ จึงเขียนง่ายและเห็นผลทันที เหมาะกับการฝึกคิดแก้ปัญหาเป็นขั้นตอน

🟩

เมื่อกดธงเขียว

เริ่มการทำงานของโปรแกรม

🚶

เคลื่อนที่

ให้ตัวละครเดินตามค่าที่กำหนด

👕

สลับชุดตัวละคร

เปลี่ยนท่าทางไปชุดถัดไปหรือชุดที่ระบุ

⏱️

รอ … วินาที

หยุดรอตามเวลาที่กำหนดก่อนทำคำสั่งต่อไป

💡 ตัวอย่าง ตั๊กแตนกระโดด: ข้อมูลเข้า = ภาพตั๊กแตน 6 ท่า · ข้อมูลออก = ภาพตั๊กแตนทำท่ากระโดด
รหัสลำลอง: เริ่มต้น → กำหนดภาพตั๊กแตน 6 ท่า → ทำซ้ำไม่รู้จบ (แสดงท่าถัดไป) → จบ

7 การวนซ้ำและตัวแปร

การวนซ้ำ ใช้เมื่อต้องทำคำสั่งเดิมหลายครั้ง ช่วยให้โปรแกรมสั้นลงและทำงานมีประสิทธิภาพขึ้น วนซ้ำได้สองแบบ

♾️

วนซ้ำไม่รู้จบ (forever)

ทำคำสั่งข้างในไปเรื่อย ๆ จนกว่าจะหยุดโปรแกรม

🔢

วนซ้ำตามจำนวนรอบ (repeat)

ใช้เมื่อรู้จำนวนรอบที่แน่นอน

ตัวแปร (Variable) คือชื่อที่ตั้งขึ้นเพื่อเก็บค่าหรือข้อมูล ณ เวลาหนึ่งเก็บได้หนึ่งค่า และเปลี่ยนค่าได้ ควรตั้งชื่อให้สื่อความหมาย บล็อกที่เกี่ยวข้อง ได้แก่ กำหนดค่า เปลี่ยนค่าเพิ่มหรือลด แสดงและซ่อนตัวแปรบนเวที

ปัญหา: แมวร้องเหมียวตามจำนวนรอบที่กำหนด
เริ่มต้น
1. กำหนดตัวแปร time เป็น 2
2. ทำซ้ำ time รอบ
   2.1 เล่นเสียงเหมียว 1 ครั้ง
จบ
💡 วาดรูปหลายเหลี่ยมด้านเท่า: มุมภายนอกรวมกันเท่ากับ 360 องศา จึงหมุนด้านละ 360 ÷ จำนวนด้าน เช่น สี่เหลี่ยมจัตุรัสหมุน 90 องศา สามเหลี่ยมด้านเท่าหมุน 120 องศา

8 การรับค่า คำนวณ และแสดงผลใน Scratch

โปรแกรมคำนวณอย่างง่ายทำงานเป็น 3 ช่วง: รับค่า → คำนวณ → แสดงผล

⌨️

ถามและรอคำตอบ

รับข้อมูลจากผู้ใช้ เก็บไว้ในค่า "คำตอบ"

➕

ตัวดำเนินการ + − × ÷

นำมาซ้อนกับบล็อกอื่นเพื่อคำนวณ

💬

พูด / พูดเป็นเวลา

แสดงผลลัพธ์หรือข้อความออกทางตัวละคร

💡 ตัวอย่าง ยกกำลังสองของจำนวนเต็ม: ข้อมูลเข้า = จำนวนเต็มใด ๆ · ข้อมูลออก = ผลของจำนวนนั้นยกกำลังสอง
เริ่มต้น → รับค่าจำนวนเต็ม → คำนวณ x × x → แสดงผลลัพธ์ → จบ
💡 ตัวอย่าง แปลงอุณหภูมิ: C = (F − 32) × 5 ÷ 9 เช่น F = 212 ได้ C = 100 ควรทดสอบด้วยค่าที่รู้ผลแน่นอนก่อนเสมอ

9 การทำงานแบบทางเลือก

การทำงานแบบทางเลือก คือการตรวจสอบเงื่อนไขก่อน แล้วตัดสินใจเลือกทำคำสั่งอย่างใดอย่างหนึ่ง

☝️

ทางเลือกเดียว (if … then)

ถ้าเงื่อนไขเป็นจริง จึงทำคำสั่ง ไม่จริงก็ข้ามไป

✌️

สองทางเลือก (if … then … else)

จริงทำอย่างหนึ่ง ไม่จริงทำอีกอย่างหนึ่ง

ตัวดำเนินการเปรียบเทียบ ที่ใช้ตั้งเงื่อนไข: = เท่ากับ · > มากกว่า · < น้อยกว่า

💡 ตัวอย่าง: ถ้าคะแนนสอบมากกว่า 80 ให้ตัวละครพูดว่า "ได้รางวัลพิเศษ"
เริ่มต้น → รับค่าคะแนนสอบ → ถ้าคะแนน > 80 พูดว่า ได้รางวัลพิเศษ → จบ
💡 เลขคู่หรือเลขคี่: นำจำนวนมาหารเอาเศษด้วย 2 ถ้าเศษเป็น 0 เป็นเลขคู่ ถ้าเศษเป็น 1 เป็นเลขคี่ (ใช้บล็อก mod)

📚 หัวข้อที่ 6–9 เรียบเรียงจากแนวสื่อ DLTV วิทยาการคำนวณ ม.1 หน่วยที่ 2 การโปรแกรม (dltv.ac.th)

💻
รู้หรือไม่? โปรแกรมคำนวณที่เราใช้ในชีวิตจริง เช่น โปรแกรมคำนวณดัชนีมวลกาย (BMI) หรือโปรแกรมสมการการเคลื่อนที่ ก็เริ่มจากอัลกอริทึมง่าย ๆ แบบนี้

  • วิเคราะห์ปัญหาต้องกำหนด วัตถุประสงค์ Input Process Output

  • โปรแกรมคำนวณ: รับค่า → คำนวณ → แสดงผล · ทางเลือกใช้ if … then (… else) กับ = > <
