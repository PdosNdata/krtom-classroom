ขั้นตอนวิธีการแก้ปัญหา · ป.4 · วิทยาการคำนวณ

← กลับหน้าหน่วย

🎯 จุดประสงค์การเรียนรู้

  • อธิบายการทำงานและคาดการณ์ผลลัพธ์โดยใช้เหตุผลเชิงตรรกะและอัลกอริทึมได้
  • ใช้เหตุผลเชิงตรรกะและอัลกอริทึมในการแก้ปัญหาอย่างง่ายได้
  • เห็นประโยชน์ของการแก้ปัญหาในชีวิตประจำวันโดยใช้เหตุผลเชิงตรรกะและอัลกอริทึม
  • อธิบายหลักการเขียนอัลกอริทึมด้วยข้อความและรหัสลำลองได้
  • อธิบายหลักการทำงานของอัลกอริทึมด้วยผังงานได้
  • แสดงอัลกอริทึมเพื่อแก้ปัญหาด้วยข้อความ รหัสลำลอง และผังงานได้อย่างถูกต้อง

1 เหตุผลเชิงตรรกะ

เหตุผลเชิงตรรกะ คือการใช้เหตุผล กฎ หรือเงื่อนไขที่เกี่ยวข้อง มาช่วยคิดแก้ปัญหาและตัดสินใจ ให้ได้คำตอบที่สมเหตุสมผลและครอบคลุมทุกกรณี

🔢

เกมซูโดกุ

ดูทั้งแถวตั้งและแถวนอน ตัวเลขห้ามซ้ำ แล้วใช้เหตุผลหาตัวเลขที่หายไป

🗺️

หาเส้นทาง

เลือกเส้นทางโดยดูเงื่อนไข เช่น ใช้บัตรคำสั่งน้อยที่สุด

🧩

หาแบบรูป

สังเกตกฎของรูปหรือตัวเลข แล้วคาดการณ์ตัวต่อไป

💡 ควรรู้: ถ้าเริ่มต้นไม่เหมือนกัน ผลลัพธ์ก็อาจไม่เหมือนกัน เช่น เดินไปโรงเรียนคนละเส้นทาง

2 อัลกอริทึมคืออะไร

อัลกอริทึม (Algorithm) คือขั้นตอนวิธีที่ใช้แก้ปัญหาอย่างเป็นระบบ มีลำดับขั้นตอนตั้งแต่เริ่มต้นจนได้ผลลัพธ์ที่ต้องการ มี 6 ขั้นตอน

  1. ทำความเข้าใจปัญหา
  2. คิดวิธีการแก้ปัญหา
  3. เรียงลำดับขั้นตอนก่อนและหลัง
  4. ทบทวนขั้นตอนในแต่ละวิธี
  5. ตรวจสอบความถูกต้องและผลลัพธ์
  6. เลือกวิธีการที่ให้ผลลัพธ์ดีที่สุด
💡 อัลกอริทึมคือการแก้ปัญหาด้วยความคิดเชิงตรรกะ เขียนได้หลายแบบ ให้เลือกแบบที่เหมาะสม กระชับ และรัดกุม

3 เขียนอัลกอริทึมด้วยข้อความและรหัสลำลอง

💬

ภาษาธรรมชาติ

เขียนบรรยายขั้นตอนด้วยภาษาที่เราใช้พูด เช่น 1) ต้มน้ำ 2) ใส่ไข่ 3) รอ 10 นาที

⌨️

รหัสลำลอง (Pseudocode)

เขียนข้อความสั้น กระชับ ใกล้เคียงภาษาโปรแกรม เช่น if ... else ...

ตัวอย่างรหัสลำลอง

  1. START
  2. if ฝนตก then กางร่ม
  3. else ใส่หมวก
  4. END
💡 ถึงจะเรียงขั้นตอนไม่เหมือนกัน แต่ถ้าเริ่มต้นและจบเหมือนกัน ก็ทำสำเร็จได้ เช่น ต้มบะหมี่กึ่งสำเร็จรูป การเลือกวิธีที่ดีที่สุดขึ้นกับเงื่อนไขที่ตั้งไว้

4 การแสดงอัลกอริทึมด้วยผังงาน (Flowchart)

ผังงาน คือแผนผังที่ใช้รูปร่างสัญลักษณ์และลูกศรแสดงขั้นตอนการทำงาน ทำให้เห็นภาพและเข้าใจง่าย

⭕

วงรี

จุดเริ่มต้นและจุดสิ้นสุด

▭

สี่เหลี่ยมผืนผ้า

กระบวนการ หรือการทำงาน

▱

สี่เหลี่ยมด้านขนาน

ข้อมูลเข้า หรือข้อมูลออก

◇

ข้าวหลามตัด

การตัดสินใจ มีทางเลือกใช่/ไม่ใช่

➡️

ลูกศร

ทิศทางลำดับการทำงาน

ตัวอย่างผังงานส่งอีเมล: เริ่มต้น → เปิดโปรแกรมอีเมล → เขียนอีเมลและใส่ผู้รับ → ตรวจสอบความถูกต้อง → กดส่ง → สิ้นสุด

5 แก้ปัญหาด้วยเหตุผลเชิงตรรกะและอัลกอริทึม

เมื่อเจอปัญหา ให้ใช้เหตุผลเชิงตรรกะคิดวิธีแก้ แล้วแสดงขั้นตอนด้วยอัลกอริทึม 3 แบบ

📝

ข้อความ

เขียนเป็นข้อ ๆ ตามลำดับ

⌨️

รหัสลำลอง

ใช้คำสั่งสั้น ๆ เช่น if else

🔷

ผังงาน

วาดสัญลักษณ์และลูกศร

🎁 ตัวอย่างปัญหา: นิชามีเงิน 800 บาท อยากซื้อของขวัญวันเกิดให้เพื่อน ต้องเลือกสินค้าที่ราคารวมไม่เกิน 800 บาท ให้เขียนอัลกอริทึมการเลือกซื้อ

📌 สรุปท้ายหน่วย

  • เหตุผลเชิงตรรกะคือการใช้เหตุผล กฎ หรือเงื่อนไขมาแก้ปัญหา
  • อัลกอริทึมคือขั้นตอนวิธีแก้ปัญหาที่เรียงลำดับชัดเจน มี 6 ขั้นตอน
  • เขียนอัลกอริทึมได้ 3 แบบ คือ ข้อความ รหัสลำลอง และผังงาน
  • ผังงานใช้วงรี สี่เหลี่ยมผืนผ้า สี่เหลี่ยมด้านขนาน ข้าวหลามตัด และลูกศร
